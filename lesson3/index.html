STEP 1

GitHub Pagesでホスティング

GitHub Pagesは、リポジトリに置いたHTML・CSS・JavaScriptなどの静的ファイルをWebサイトとして公開できるサービスです。

01 Repository新しいリポジトリを作る
02 Uploadindex.htmlとCSVを置く
03 SettingsPagesの公開元を設定
04 Open URL発行されたURLを開く

公開URLの例
https://ユーザー名.github.io/リポジトリ名/

なぜGitHub Pagesを使う？

特別なサーバを用意せず、更新履歴を残しながらWebアプリを共有できます。URLを知っている人は、PCやスマートフォンからアクセスできます。

GitHub公式手順
SECURITY

公開前に確認する、超重要事項

GitHub Pagesで公開した画面だけでなく、公開リポジトリのソースコードやデータも世界中から閲覧できます。

×
個人情報を含めない
本名、電話番号、住所、非公開の業務データなど
×
秘密情報をコードへ書かない
APIキー、パスワード、アクセストークンなど
×
「URLを知られなければ安全」と考えない
公開したファイルは検索・共有・複製される可能性があります
STEP 2

LeafletとOpenStreetMapを知ろう

Leaflet

Webページ上で地図を操作するためのJavaScriptライブラリ。マーカーや線、ポップアップなどを追加できます。

公式リファレンス

OpenStreetMap

世界中の人が編集するオープンな地理データ。Leafletでは背景地図のタイルとして表示できます。

著作権とライセンス

Web GIS

地理情報をWeb上で表示・検索・分析する仕組み。位置情報と行政データを結び付けられます。

OpenStreetMapの帰属表示は消さない：地図右下の「© OpenStreetMap contributors」は、利用条件上必要なクレジットです。

LEAFLET BASIC

地図・マーカー・線・レイヤ切替を作る

左のコードをコピーして index.html として保存します。内灘駅と道の駅内灘サンセットパークを線で結ぶ例です。

index.html（Leaflet基本）
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>内灘町 Leaflet入門マップ</title>
  <link rel="stylesheet"
    href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css">
  <style>
    body { margin: 0; }
    #map { width: 100vw; height: 100vh; }
    .red-pin { color:#fff; background:#b44848; border:3px solid #fff;
      width:24px; height:24px; border-radius:50% 50% 50% 0;
      transform:rotate(-45deg); box-shadow:0 2px 7px #0005; }
  </style>
</head>
<body>
  <div id="map"></div>
  <script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>
  <script>
    const map = L.map('map').setView([36.657, 136.648], 13);

    const osm = L.tileLayer(
      'https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png',
      { attribution:'&copy; OpenStreetMap contributors' }
    ).addTo(map);

    const station = L.marker([36.633524, 136.633933])
      .bindPopup('<b>内灘駅</b><br>北陸鉄道浅野川線の駅です。');

    const redIcon = L.divIcon({
      className:'', html:'<div class="red-pin"></div>',
      iconSize:[24,24], iconAnchor:[12,24]
    });
    const sunset = L.marker([36.659151, 136.648919], {icon:redIcon})
      .bindPopup('道の駅内灘サンセットパーク');

    const route = L.polyline([
      [36.633524,136.633933], [36.659151,136.648919]
    ], {color:'#196DAC', weight:4});

    const features = L.layerGroup([station, sunset, route]).addTo(map);
    L.control.layers({'基本マップ（OSM）':osm}, {'表示アイテム':features})
      .addTo(map);
    station.openPopup();
  </script>
</body>
</html>

DATA SCHEMA

列番号ではなく「見出し名」で読む

元のコードにあった cols[5] のような固定位置は、今回のCSVでは列構成が異なるため使えません。見出し名で取得すると安全です。

見出し名地図での用途
名称ポップアップのタイトル
緯度 / 経度マーカーの位置
男性トイレ総数設備情報
女性トイレ総数設備情報
バリアフリートイレ数設備情報
利用可能時間特記事項利用案内

今回使うPapa Parse

CSVの1行目を見出しとして読み込み、各行をオブジェクトへ変換します。項目中のカンマや引用符にも対応しやすくなります。

row['名称']
Number(row['緯度'])
row['車椅子使用者用トイレ有無']

データの列順が変わっても、見出し名が同じならコードを直さずに読み込めます。

STEP 4

CSVの17地点を地図にプロットする

fetchでCSVを読み込み、Papa Parseで解析し、各行の緯度・経度にマーカーを追加します。

index.html（CSV読み込み版）
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>内灘町 公衆トイレマップ</title>
  <link rel="stylesheet"
    href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css">
  <style>body{margin:0} #map{width:100vw;height:100vh}</style>
</head>
<body>
  <div id="map"></div>
  <script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/papaparse@5.5.3/papaparse.min.js"></script>
  <script>
    const map = L.map('map').setView([36.657,136.648],13);
    L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png',{
      attribution:'&copy; OpenStreetMap contributors'
    }).addTo(map);

    // 外部データをHTMLへ入れる前に、危険な記号を無害化する
    const escapeHtml = value => String(value ?? '')
      .replaceAll('&','&amp;').replaceAll('<','&lt;')
      .replaceAll('>','&gt;').replaceAll('"','&quot;')
      .replaceAll("'",'&#039;');

    fetch('./toilet_uchinada.csv')
      .then(response => {
        if (!response.ok) throw new Error('CSVを取得できません');
        return response.text();
      })
      .then(text => {
        const result = Papa.parse(text,{header:true,skipEmptyLines:true});
        const markers = [];

        result.data.forEach(row => {
          const lat = Number(row['緯度']);
          const lng = Number(row['経度']);
          if (!Number.isFinite(lat) || !Number.isFinite(lng)) return;

          const popup = `
            <b style="color:#196DAC;font-size:1.1em">
              ${escapeHtml(row['名称'])}
            </b><hr>
            男性用：${escapeHtml(row['男性トイレ総数'])}基 / 
            女性用：${escapeHtml(row['女性トイレ総数'])}基<br>
            バリアフリー：${escapeHtml(row['バリアフリートイレ数'])}基<br>
            車椅子対応：${escapeHtml(row['車椅子使用者用トイレ有無'])}<br>
            ${escapeHtml(row['利用可能時間特記事項'])}`;

          markers.push(L.marker([lat,lng]).addTo(map).bindPopup(popup));
        });

        if (markers.length) {
          map.fitBounds(L.featureGroup(markers).getBounds(),{padding:[25,25]});
        }
      })
      .catch(error => {
        console.error(error);
        alert('CSVの読み込みに失敗しました。ファイル名と配置を確認してください。');
      });
  </script>
</body>
</html>

TROUBLESHOOTING

地図が表示されないときの確認順

CHECK 1

地図の高さ

#mapに高さがないと、地図は0pxになり見えません。

CHECK 2

ファイル名

toilet_uchinada.csvと完全一致しているか。

CHECK 3

同じ階層

HTMLとCSVが同じフォルダに置かれているか。

CHECK 4

公開URL

file://ではなくGitHub Pagesから開いているか。

CHECK 5

列見出し

「緯度」「経度」「名称」がCSVにあるか。

CHECK 6

開発者ツール

F12 → Consoleで赤いエラーを確認。

CHECK 7

外部ライブラリ

Leaflet・Papa ParseのURLが読み込めるか。

AIへ渡す

エラー全文

「動かない」だけでなく、赤いエラーをコピーして相談。
